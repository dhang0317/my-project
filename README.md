# L'Atelier de Lecture — 法式羊皮紙沉浸式文章閱讀與反白翻譯學習系統

**L'Atelier de Lecture** 是一個專為法文學習者與閱讀愛好者打造的沉浸式法文閱讀器與生字管理系統。採用「法式羊皮紙暖調書房風 (Editorial Warm Paper)」設計，免設定任何付費 AI API Key 即可享受反白即時繁體中文翻譯、動詞變位原形還原、句型語法拆解，並將你的文章書庫與生字本自動同步至 GitHub 雲端資料庫。

## ✨ 核心功能

1. **多元法文文章上傳與匯入**：
   - **直接貼上純文字** 或 **拖曳上傳 `.txt` / `.md` 檔案**。
   - **輸入法文新聞 / 維基百科網址 (URL)** 自動擷取乾淨正文。
   - 內建精選法文範例文章（《小王子 Le Petit Prince》狐狸篇章、巴黎咖啡館文化、法國城市生態轉型報導）。
2. **智慧雙模式反白翻譯（完全免費、免 API Key）**：
   - **反白單字／片語**：上方立即彈出輕巧翻譯氣泡，同時於右側固定面板顯示**動詞原形還原 (Infinitif / Lemme)**、詞性、時態/陰陽單複數變化、省音縮寫解析與字典多重釋義。
   - **反白整句／段落**：提供流暢繁體中文整句翻譯，並自動拆解句中的法文語法結構（如 `ne ... que`、`ne ... plus`、副動詞 `en + -ant`、強調句型 `C'est ... qui/que`、縮合冠詞等）。
3. **四色螢光筆重點標記 & 生字本系統**：
   - 支援琥珀黃、勃根地紅、鼠尾草綠、迷霧藍四色螢光筆標記文章重點，重開文章依然保留高亮。
   - 自動收錄原句上下文至「生字本」，支援**互動式翻面記憶卡 (Flashcards)** 複習，以及一鍵匯出 **Anki / CSV 格式**與 **JSON 完整備份**。
4. **GitHub 雲端資料庫雙軌同步 (`data/library.json`)**：
   - **本地開發伺服器模式 (`npm run dev`)**：後端自動將新增的文章、螢光筆標記與生字寫入 `data/library.json` 並自動執行 Git Commit & Push 同步至 GitHub 儲存庫。
   - **GitHub Pages 靜態網頁模式**：支援填入 GitHub Personal Access Token，直接從手機或外部電腦瀏覽器透過 GitHub REST API 跨裝置讀寫雲端資料庫。

## 🚀 快速啟動

```bash
npm run dev
```

啟動後打開 `http://localhost:3000` 即可開始使用。
